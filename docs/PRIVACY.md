# Privacy policy

Skarb is a self-hosted, single-user personal finance application. It is operated by its
owner for their own use only; there are no other users.

- All financial data (accounts, transactions, bank access tokens) is stored exclusively in a
  database on the owner's own machine. Nothing is sent to any third-party server operated by
  Skarb.
- Bank data is retrieved solely from the owner's own accounts, via the banks' official APIs
  and licensed open-banking providers (Enable Banking), with the owner's explicit consent
  given at the bank.
- Access to bank data can be revoked at any time at the bank, in the open-banking provider's
  portal, or by deleting the connection in Skarb.
- Exchange rates are fetched anonymously from a public rates API; no personal data is
  transmitted in that request.
- No analytics, tracking, or advertising of any kind.

Data-protection contact: the repository owner (see the GitHub profile).
